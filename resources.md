# Resources — Videos, Channels, Platforms, Books (with Links)

The master list of everything referenced across the 7 phases, organized so
you can find anything quickly. Everything here is **kid-safe**,
**free or freemium**, and **vetted for an 11–12 year old**.

> Pin this file. You'll reach for it often.

> A note on links: where a video is famous and stable, the link goes
> straight to it. Where a video might get re-uploaded or replaced, the link
> is a YouTube *search* URL with the exact title — the right video lands
> as the top result and the link never 404s.

## 5. Books (optional — most learning is screens at this age)

These are the rare books worth keeping near the laptop.

### For the kid

- [**Hello Ruby** series by Linda Liukas](https://www.helloruby.com) — gorgeous CS picture books;
  start with *"Adventures in Coding"*.
- [**Python for Kids** (Jason R. Briggs)](https://nostarch.com/pythonforkids) — the most kid-friendly Python book ever written.
- [**Coding Games in Python** (DK Publishing)](https://www.dk.com/uk/book/9780241317761-coding-games-in-python/) — heavily illustrated step-by-step projects.
- [**Computer Coding for Kids** (Carol Vorderman, DK)](https://www.dk.com/uk/book/9780241317730-computer-coding-for-kids/) — picture-book pacing.

### For the parent (helps you teach)

- [**Computational Fairy Tales** by Jeremy Kubica](https://www.amazon.com/Computational-Fairy-Tales-Jeremy-Kubica/dp/1477550299) — short stories that smuggle CS concepts in.
- **The Manga Guide to Statistics** by Shin Takahashi — visual stats, age-flex.
- [**Storytelling with Data** (Cole Nussbaumer Knaflic)](https://www.storytellingwithdata.com/books) — the *only* book on data viz you ever need.
- [**Hands-On Machine Learning** by Aurélien Géron](https://www.oreilly.com/library/view/hands-on-machine-learning/9781098125967/) — reference for the parent when the kid asks a hard ML question.

### For later (high school)

- [**Python Crash Course** by Eric Matthes](https://nostarch.com/pythoncrashcourse2e)
- [**An Introduction to Statistical Learning** (ISL) — free PDF](https://www.statlearning.com)

## 7. Communities (with adult supervision)

Most are 13+ — check ToS. Used **only with parent present** at this age.

- [**Kaggle**](https://www.kaggle.com) — datasets, kernels (notebooks), kind community.
- [**Scratch community**](https://scratch.mit.edu/explore/projects/all) — kid-friendly, well-moderated.
- [**Replit community**](https://replit.com/community) — share Python projects.
- [**Code.org community**](https://code.org/educate/community) — for younger users.

**Avoid until 13+ (or with very tight supervision):**
- StackOverflow comment sections (tone can be harsh)
- Reddit programming subs
- Discord servers (unless parent runs / verifies the server)
