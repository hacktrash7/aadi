# Resources — Videos, Channels, Platforms, Books

The master list of everything referenced across the 7 phases, organized so
you can find anything quickly. Everything here is **kid-safe**,
**free or freemium**, and **vetted for an 11–12 year old**.

> Pin this file. You'll reach for it often.

---

## 4. Curated kid-friendly datasets (for Phases 5–7)

Searchable on Kaggle by these names:

- **Pokémon** — stats, types, generations (gateway dataset)
- **Palmer Penguins** — small, clean, perfect for first ML
- **Iris** — classic 4-feature flower dataset (built into scikit-learn)
- **Titanic** — survival prediction, *the* legendary first ML dataset
- **FIFA player stats** (yearly)
- **IPL ball-by-ball / matches**
- **NBA player stats**
- **Disney+ titles** / **Netflix titles**
- **Spotify Top 200** — songs and audio features
- **IMDB Top 1000 movies**
- **World Happiness Report**
- **World Bank country indicators** (via Our World in Data)
- **Daily weather** for your home city (NOAA, IMD, or Kaggle)
- **YouTube trending videos** (regional)
- **Olympic athletes & medals**
- **Animal Crossing** villagers / fish
- **Star Wars characters / Harry Potter characters**

Pick datasets the kid already *cares about*. Don't make this academic.

## 5. Books (optional — most learning is screens at this age)

These are the rare books worth keeping near the laptop.

### For the kid

- **"Hello Ruby"** series by Linda Liukas — gorgeous CS picture books;
  start with *"Adventures in Coding"*. (Aimed slightly younger, but
  many 11-year-olds still love them.)
- **"Python for Kids: A Playful Introduction to Programming"** by Jason
  R. Briggs — the most kid-friendly Python book ever written.
- **"Coding Games in Python"** (DK Publishing) — heavily illustrated
  step-by-step projects.
- **"How to Code in 10 Easy Lessons"** (DK / Usborne) — picture-book
  pacing, perfect for Phase 1.

### For the parent (helps you teach)

- **"Computational Fairy Tales"** by Jeremy Kubica — short stories that
  smuggle CS concepts in.
- **"The Manga Guide to Statistics"** by Shin Takahashi — visual stats,
  age-flex.
- **"Storytelling with Data"** by Cole Nussbaumer Knaflic — the *only*
  book on data viz you ever need. Read for yourself, apply to Phase 4–7.
- **"Hands-On Machine Learning"** by Aurélien Géron — reference for the
  parent when the kid asks a hard ML question. (Far too advanced for
  the kid directly.)

### For later (high school)

- **"Python Crash Course"** by Eric Matthes.
- **"An Introduction to Statistical Learning"** (ISL) — by then the kid
  can read it.

## 7. Communities (with adult supervision)

Most are 13+ — check ToS. Used **only with parent present** at this age.

- **Kaggle** — datasets, kernels (notebooks), kind community.
- **Scratch community** — share-your-project, very kid-friendly,
  generally well-moderated.
- **Replit community** — share Python projects.
- **Code.org community spaces** — for younger users.

**Avoid until 13+ (or with very tight supervision):**
- StackOverflow comment sections (tone can be harsh)
- Reddit programming subs
- Discord servers (unless parent runs / verifies the server)
