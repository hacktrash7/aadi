# Aadi's Data Science Journey

A visual, project-driven curriculum that takes a curious 6th-grader from
*"I've never coded"* all the way to *"I built and explained my own machine
learning project."*

The design philosophy in one line:

> **See it → Play with it → Build it → Explain it.**

Every concept first appears as a picture, animation, or video. Then the kid
plays with it on an interactive platform. Then they build a small thing.
Then they explain it back in their own words — that's how we know it stuck.

Each phase doc follows the same shape so the kid (and the parent) always
knows what to expect:

1. **Why this phase exists** (in plain language)
2. **What we're learning** (concepts)
3. **Watch** (videos + visual demos)
4. **Play** (interactive platforms / sandboxes)
5. **Build** (mini-projects)
6. **Explain back** (talk-it-out checkpoint)
7. **Exit ticket** (the one thing you must be able to do to move on)

## The 7-phase roadmap at a glance

| # | Phase                  | Big idea                                                  | Tools / Platforms                                     | Roughly how long\* |
|---|------------------------|-----------------------------------------------------------|-------------------------------------------------------|--------------------|
| 1 | Foundation             | Think like a computer (no syntax yet)                     | Code.org, Scratch, Blockly, logic puzzles             | 3–4 weeks          |
| 2 | Python Basics          | Write code that does something fun                        | Replit, Mimo, CodeCombat, Trinket                     | 6–8 weeks          |
| 3 | Problem Solving        | Break problems down, code the solution                    | CodingBat, Edabit, HackerRank "Easy", CodeChef Kids   | 6–8 weeks          |
| 4 | Data & Stats           | Numbers tell stories, charts make them obvious            | Google Sheets, Khan Academy, Desmos, Brilliant        | 3–4 weeks          |
| 5 | Data Science with Code | Load real data, ask it questions, draw pictures from it   | Jupyter, pandas, matplotlib, seaborn, Kaggle datasets | 8–10 weeks         |
| 6 | Machine Learning       | Teach the computer to learn from examples                 | Teachable Machine, scikit-learn, Streamlit            | 6–8 weeks          |
| 7 | Capstone               | One *real* project, presented to family like a TED talk   | Everything above + slides + a short video             | 4 weeks            |

\* These are pacing *guides*, not deadlines. A 6th-grader has school. The
schedule is **3 sessions of 45–60 minutes per week**. Slow down whenever it
stops being fun — that's a signal, not a failure.

## Non-negotiable principles

1. **Visuals before symbols.** If we can't draw it, we don't understand it yet.
2. **Tiny wins beat big lectures.** Each session should end with *something
   that works* — a running program, a chart, a solved puzzle.
3. **One concept at a time.** Never introduce two new ideas in the same
   session.
4. **The kid teaches the parent at the end of every session.** 5 minutes.
   This is the most important habit in the whole curriculum.
5. **Mistakes are evidence, not embarrassment.** We celebrate red error
   messages — they're how the computer talks.
6. **No memorizing syntax.** Google, docs, and (carefully supervised) AI are
   tools. We memorize *ideas*, not commas.

---

## What "done" looks like

By the end of Phase 7 the kid should be able to:

- Open a Jupyter notebook, load a CSV they've never seen before, and answer
  three interesting questions about it.
- Train a simple machine learning model and *explain* what it learned and
  what it got wrong.
- Sit a relative down and walk them through one of their capstone projects
  for 10 minutes — confidently, in their own words.

That's the real goal. The code is a side effect.
